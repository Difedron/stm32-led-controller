# STM32 LED Controller

Проект выполнен в рамках лабораторной работы №2 по дисциплине «Программирование микроконтроллеров».

Реализовано управление восемью светодиодами на микроконтроллере STM32F446 с помощью физических кнопок и команд по UART. Программа написана на C с использованием CMSIS, без HAL, с прямым обращением к регистрам микроконтроллера.

## Реализованные функции

- Управление восемью светодиодами через GPIO (PC4–PC11).
- Включение и выключение всех светодиодов.
- Управление состоянием отдельного светодиода.
- Последовательное изменение количества включённых светодиодов с помощью двух физических кнопок.
- Приём команд по USART2 с использованием прерываний.
- Обработка команд по бинарному протоколу.
- Получение текущего состояния светодиодов и отправка ответов по UART.
- Поддержка команды Echo для проверки обмена данными.

## Бинарный протокол

Для обмена данными используется пакет фиксированной структуры с переменной длиной поля данных:

`[Header] [Length] [Slave ID] [Command] [Data...] [Terminator]`

| Поле | Размер | Описание |
|---|---|---|
| Header | 1 байт | Начало пакета (`0xAA`) |
| Length | 1 байт | Общая длина пакета в байтах |
| Slave ID | 1 байт | Адрес устройства (`0x01`) |
| Command | 1 байт | Код команды |
| Data | 0 и более байт | Данные команды |
| Terminator | 1 байт | Конец пакета (`0x55`) |

Поддерживаемые команды:

| Код | Команда |
|---|---|
| `0x01` | Echo — возврат полученных данных |
| `0x02` | Включение всех светодиодов |
| `0x03` | Выключение всех светодиодов |
| `0x05` | Получение текущего состояния светодиодов |
| `0x06` | Управление отдельным светодиодом |

Пример включения всех светодиодов:

`AA 05 01 02 55`

Пример включения светодиода с индексом 2:

`AA 07 01 06 02 01 55`

В последнем примере `02` — индекс светодиода (от 0 до 7), `01` — включение (`00` — выключение).
